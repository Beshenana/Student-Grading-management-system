# Student Grading Management System (SGMS)

## Project Overview

The **Student Grading Management System (SGMS)** is a proposed web-based system designed to manage student academic grades and results within a university environment.

The system aims to organize student records, instructor information, courses, grade entry, and academic result reporting in one centralized platform.

This project is being developed as a Web Programming course project at Haramaya University.

## Project Objectives

- Organize student academic records.
- Manage student, instructor, and course information.
- Provide a structured process for entering and managing grades.
- Allow students to view their academic results.
- Support grade reports and grade review requests.
- Improve the organization and accessibility of academic grading information.

## Proposed System Modules

### 1. Authentication
- Login
- Password recovery

### 2. Administrator
- Admin dashboard
- Manage students
- Manage instructors
- Manage courses
- Manage users

### 3. Instructor
- Instructor dashboard
- Enter student grades
- View and manage grade records

### 4. Student
- Student dashboard
- View academic results
- View grade reports
- Submit grade review requests
